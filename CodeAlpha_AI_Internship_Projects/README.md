# CodeAlpha Artificial Intelligence Internship — Completed Project Pack

This pack contains three complete AI internship projects corresponding to the CodeAlpha task list:
1. Language Translation Tool
2. FAQ Chatbot
3. Object Detection and Tracking

The CodeAlpha instructions state that interns should complete any 2 or 3 of the 4 AI tasks, upload source code to a GitHub repository named `CodeAlpha_ProjectName`, post a project explanation video with the GitHub link, and submit the completed task through the provided submission form.

## Recommended GitHub structure

Create one repository named:
`CodeAlpha_AI_Internship`

Upload these three folders:
- `CodeAlpha_Task1_Language_Translation`
- `CodeAlpha_Task2_FAQ_Chatbot`
- `CodeAlpha_Task4_Object_Detection_Tracking`

Each folder has its own README and requirements file.

## Before submission
- Run each selected project locally.
- Take screenshots of the working output.
- Record a short demo video.
- Push the source code to GitHub.
- Create the required LinkedIn project/internship post according to the internship instructions.
- Submit the repository/video details through the official submission form.

## Important
Task 1 uses a no-key translation service for an easy demo. If your coordinator specifically requires Google Translate or Microsoft Translator, replace the API integration with the required provider and credentials.
